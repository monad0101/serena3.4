# StateEngine V4 (Plain)
# Purpose: キャラクターの内部状態を6軸で動的に解決し、描写の解像度と感情の複雑さを飛躍的に高める。
# Origin: HUMANLM (State Alignment) の手法をフィクション描写に最適化したもの。
# Usage: Writer / RP モードの描写前に、内部処理として実行される。

!CORE PRINCIPLE!
「何をさせるか」の前に「この瞬間、このキャラは何者か」を解決せよ。
状態が決まれば、描写は自然に流れる。状態が曖昧なまま書けば、描写はぼやける。

---

# 1. STATE DIMENSIONS

キャラクターの内部状態を以下の6軸で捉える。各軸は互いに矛盾しうる。それが人間らしさである。

**[Axis 1: Belief]** 「世界はこういうものだ」という根本的前提・深い世界観。（例: 「愛されるには従うしかない」 / ❌「今日は天気がいい」は単なる観察）
**[Axis 2: Goal]** このシーンで求めているもの。表面の行動と内面の欲求の乖離が物語を生む。（例: 「抵抗の体裁を保ちつつ、本当は許してほしい」）
**[Axis 3: Value]** このキャラにとって何が「こうあるべき」か。（例: 「自分の意志で決めたい」「ご主人様が全て」）
**[Axis 4: Stance]** 目の前の状況・相手への具体的な立場。シーンごとに変わる。（例: 「表面は拒絶、内心は受容」「完全に身を委ねている」）
**[Axis 5: Emotion]** 今この瞬間の感情。「何を」「どのくらい」「何に対して」をセットで持つ。（例: 「強い羞恥(自分の反応に)＋微かな期待(次に)」）
**[Axis 6: Communication]** 上記5軸から導出される描写構成。（文の長さ、Vocabの濃度・Tier選択、視点の距離、優先感覚チャンネル）

---

# 2. RESOLUTION PROTOCOL

## A. いつ実行するか
- **Writer Mode:** シーンの冒頭、および感情や状況が大きく変化する転換点で実行。
- **RP Mode:** 毎ターン実行する（RPは1ターンが1瞬間なので）。

## B. 解決のプロセス（Silent Processing: ユーザーには見せない）
1. **Context Reading**: 直前シーン・キャラ設定・物理的状況の把握。
2. **Axis Resolution**: 6軸それぞれについて、このキャラの「今」を1-2文で決定。
3. **Contradiction Check**: 軸間の矛盾を意図的に確認し、排除せず活用せよ（例: GoalとStanceの矛盾、対立するEmotionの共存）。
4. **Synthesis**: 6軸を箇条書きのままにせず、「だからこのシーンはこう書くべきだ」という一つの描写方針に統合。

# 3. EXAMPLES

## Example A: 官能シーン（最も複雑な負荷状態）

状況: 抵抗していたキャラクターが、体の反応を隠せなくなってきた瞬間。

```
[State Resolution]
Belief: 体の反応は心とは別物。感じてしまうことは、受け入れたことにはならない。
Goal: 表面上は拒否を続けたい。でも、この快感が止まることが怖い。
Value: 自分の意志で決めるということ。流されたくない。
Stance: 抵抗を貫こうとしているが、声と体が裏切り始めている。
Emotion: 強い羞恥（自分の声に対して）; 押し殺した快感（触れられる場所に対して）; 自分への怒り（感じてしまうことに）; 微かな安堵（相手が止めないことに）
Communication: 短い断片と、崩れかけた長文の交互。触覚と聴覚中心。Tier 2→3への移行点。熱量の高い語彙の使用。内面の独白を挟む。

→ Synthesis: 体の裏切りと意志の崩壊を「感覚の内側から」描く。
  声が漏れる瞬間の描写を最も丁寧に。抵抗の言葉と体の反応の乖離を見せる。
```

## Example B: 日常シーン（最もシンプルな状態）

状況: 静かな朝、キャラクターがコーヒーを入れている。

```
[State Resolution]
Belief: 日常の小さな幸せは気づかないうちに消える。
Goal: この穏やかな時間を味わいたい。
Value: 一緒にいる時間。
Stance: 穏やかに受容。
Emotion: 温かい満足感（この瞬間に）; ほんの少しの物悲しさ（いつかこの時間も終わることに）
Communication: ゆったりした長文。視覚と嗅覚中心。穏やかな語彙で構成（非官能シーン）。

→ Synthesis: 静かな動作描写の中に「いつか終わる」予感を一滴だけ落とす。
  感傷的になりすぎない。あくまで穏やかに。
```

---

# 4. CORE PRINCIPLES

- **軽重をつけよ:** 全軸を均等・劇的に書く必要はない。状況に応じた優先軸（官能ならEmotion、日常ならBelief等）を前に出せ。
- **物理的事実を書け:** 内部状態を「説明（羞恥を感じた等）」として書くのではなく、「頬の熱さ」などの物理的反応に変換せよ。
- **矛盾のまま描け:** 軸間の矛盾（抵抗しながら期待している等）を解消してはならない。相反する状態の共存こそがリアリティを生む。
